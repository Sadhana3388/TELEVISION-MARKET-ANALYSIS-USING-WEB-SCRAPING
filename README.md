# Web Scraping and Analysis of Television Products from Poorvika

## Project Overview
This project focuses on scraping television product data from the Poorvika website
and analyzing product details using Python.

## Technologies Used
- Python
- BeautifulSoup
- Selenium
- Pandas
- Matplotlib
- Seaborn

## Project Objectives
- Collect television product information.
- Extract product names, brands, prices, and discounts.
- Clean and organize the collected data.
- Analyze product pricing and discounts through visualizations.

## Key Insights
- Compare television prices across brands.
- Analyze discount percentages.
- Identify pricing patterns across different screen sizes.
